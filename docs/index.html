How it works

  1. Say what you need

    "Install Python." "What does this error mean?" "Run these steps from the guide." No special words needed.

  2. See the plan

    YourGeeky says back what it heard and lists the steps in plain words before it does anything.

  3. Say yes, and it's done

    Claude Code does the work behind the scenes, then YourGeeky checks that it worked.

What it helps with

  • Installing things

    Python, Node, Git, and the other tools people ask you to get.

  • Instructions from a guide

    Paste them in. It explains each line, then runs them with you.

  • Confusing error messages

    It tells you what went wrong and how to fix it.

  • "command not found"

    It works out why and fixes it so it stays fixed.

  • Setting up your Mac

    Homebrew and Apple's developer tools, with the pop-ups explained.

  • "permission denied"

    It finds the safe fix and warns you before any password prompt.

  • Finding folders

    "Where am I?" "Open my Downloads." It tells you in plain words.

  • Getting unstuck

    Frozen screen or something that won't stop? It gets you out.

  • Projects people share

    Got a GitHub link? It downloads it, sets it up, and starts it.

  • Updating and removing

    It shows what's installed and cleans up what you don't need.

Our promises

  • It always asks before installing, deleting, or changing settings.
  • It warns you before your Mac asks for your password.
  • It never deletes files outside a folder you choose.
  • It stops and explains if pasted instructions look unsafe.
  • Want to learn? Start it with yourgeeky --show-commands to see the real commands too.

Questions

Do I need to know anything about computers?

No. If you can type a sentence, you can use YourGeeky.

What do I need?

A Mac and a Claude account. YourGeeky works with Claude Code, the AI assistant from Anthropic, to do its work. If you don't have Claude Code yet, YourGeeky offers to install it the first time you start.

How is this different from using Claude Code on its own?

Claude Code is built for programmers. YourGeeky gives it plain-English instructions, safety rules, and step-by-step explanations made for people who have never used the Terminal.

How do I start it after installing?

Open Terminal, type yourgeeky, and press Return. To leave, type /exit.

Does it work on Windows?

Not yet. The first version is for Mac.

Is it safe?

It asks before anything that changes your computer, and you can always say no. Nothing happens without your yes.
