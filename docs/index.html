The Terminal, in plain English.
Just say it.

Someone told you to "just open Terminal and run this"? Getting into the Terminal is scary for most of us. We're not programmers! YourGeeky does it with you. Say what you need out loud, or type it, in your own words. It explains each step and asks before changing anything.

YourGeeky is free. It runs on Google's free AI, or on Claude Code from Anthropic if you already have a paid Claude plan. Setting it up takes one line.

Set up YourGeeky

Talk to it like a person

No typing needed. YourGeeky understands everyday speech, even when your Mac mishears a word.

  1. Press the microphone key

    Or press Fn twice. Your Mac starts listening. It's built in and free.

  2. Say what you need

    "Can you install Python for me?" "Why does it say permission denied?" Talk the way you'd talk to a friend.

  3. Press Return

    YourGeeky works out what you meant, says it back to check, and then gets to work.

The 20 things people most often need the Terminal to install

Roughly in order, most common first. YourGeeky can set up any of them. Just say the name.

  1. Homebrew: the free tool that installs most of the others on this list
  2. Apple's Command Line Tools: the basic building blocks almost everything else needs
  3. Python: for classes, data, automation and many AI tools
  4. Git: downloads code projects and keeps track of changes
  5. Node.js and npm: runs lots of web tools and website projects
  6. Python add-ons (pip): the extra packages a class or project tells you to get
  7. The code command for VS Code: opens a folder in Visual Studio Code from the Terminal
  8. Java: for Minecraft servers, school courses and some older apps
  9. Docker: runs an app in its own sealed-off box
  10. GitHub's command-line tool (gh): sign in to GitHub and grab or share projects
  11. Anaconda or Miniconda: a Python setup used in data science courses
  12. Jupyter Notebook: the notebook pages many data and AI classes use
  13. FFmpeg: converts and shrinks video and audio files
  14. ImageMagick: resizes and converts pictures in bulk
  15. wget: downloads files from a web address
  16. Ruby and Jekyll: for building simple websites, including GitHub Pages
  17. CocoaPods: add-ons for people building iPhone apps
  18. PostgreSQL or MySQL: databases that apps and courses ask you to set up
  19. Ollama: runs AI models right on your own Mac
  20. Cloud tools (AWS, Google Cloud, Firebase): to put a website or app online

Is this safe?

Yes. Pasting commands you don't understand into the Terminal is a fair thing to be careful about, so here is exactly what the install line does, and nothing more.

What the install line does

  1. Downloads YourGeeky's installer from this website. It's a plain text file, so anyone can read every line of it before running it.
  2. Puts YourGeeky in its own folder called .yourgeeky inside your home folder. It doesn't touch system files and doesn't ask for your Mac password.
  3. Adds one line to your Terminal settings (only if needed) so that typing yourgeeky works.
  4. Asks you one question, then installs either Google's free AI or Claude Code, using the official installer from Google or Anthropic.

Why it's safe to use

  • It asks before it acts. Before running anything that changes your Mac, it shows you a Yes/No choice. Nothing happens unless you say yes (hit Return), and you can always say no.
  • You stay in charge of your password. If your Mac needs your password, you type it yourself. YourGeeky warns you before it's needed.
  • It has built-in safety rules. It never deletes files outside a folder you choose. It won't run anything it can't explain in one sentence. If instructions you paste look risky, it stops and tells you why.
  • It's easy to remove. Ask YourGeeky to uninstall itself, or delete the hidden .yourgeeky folder in your home folder.

How do I know YourGeeky won't do something bad?

It's a fair question to ask about anything that works on your computer. Here's the honest answer.

You approve every change. YourGeeky can look things up on its own, like checking whether Python is installed. But before it changes anything, it stops, shows you the exact command, and waits for your Yes. If you never say yes, nothing changes.

There's nothing hidden. All of YourGeeky's code is public on GitHub for anyone to check. It's just a few plain text files, including the plain-English instructions it gives the AI. Anyone can read those instructions on GitHub, and people who know computers can check that it does what this page says.

It only works while you're using it. It doesn't run in the background, start up on its own, or keep watching your computer. When you close the Terminal window, it stops.

We don't collect anything. YourGeeky has no ads, no tracking and no account with us. It never sends your conversations to us.

The AI comes from companies you've heard of. The thinking is done by Google's or Anthropic's AI, which have their own safety rules on top of ours.

And the honest part: no software is perfect, and AI can misunderstand. That's why the final say is always yours. If a step doesn't make sense, say no, or ask "why?", and it will explain before doing anything.

Good to know

  • To understand your request, what you type or say (and the results of the commands it runs) is sent to the AI you chose, Google or Anthropic, under their privacy terms. Don't share passwords or private information in the chat.
  • AI can make mistakes. That's exactly why YourGeeky explains each step and waits for your yes. If something doesn't sound right, say no and ask it why.

Questions

Can I talk instead of typing?

Yes. Once YourGeeky is running, press the microphone key on your keyboard (or press Fn twice) and just say what you need. Your Mac's built-in Dictation types your words in for you, then press Return. Don't worry if it mishears a word. YourGeeky works out what you meant and checks with you if it's not sure. If Dictation is off, turn it on in System Settings, under Keyboard.

Do I need to know anything about computers?

No. If you can type a sentence, you can use YourGeeky.

What do I need?

A Mac and a free Google account. If you already pay for Claude, you can use that instead. The install line sets up everything else.

Is it free?

Yes. YourGeeky is free, and so is Google's AI that it uses by default, up to a daily limit. If you want more, you can switch to Claude Code, which needs a paid Claude plan (Pro starts at $20 a month).

How is this different from using the AI on its own?

Google's AI and Claude Code are built for programmers. YourGeeky gives them plain-English instructions, safety rules, and step-by-step explanations made for people who have never used the Terminal.

How do I start it after installing?

Open Terminal, type yourgeeky, and press Return. Now you're chatting with YourGeeky. Just say what you need: press the microphone key (or Fn twice), speak, then press Return. Or type it in plain English if you prefer. To leave, type /exit. After that, the Terminal is back to normal and only understands commands again.

Does it work on Windows?

Not yet. The first version is for Mac.

Is it safe?

It asks before anything that changes your computer, and you can always say no. Nothing happens without your yes. See Is this safe? for exactly what the install does.
